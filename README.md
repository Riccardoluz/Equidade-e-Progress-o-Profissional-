# Equidade e Progressão Profissional: Análise Comparativa Índia x EUA

## 📌 Contextualização
Este projeto analisa fatores que influenciam remuneração e retenção de colaboradores em diferentes contextos culturais e econômicos, comparando dados de empresas da Índia e dos Estados Unidos.  
Os principais temas abordados incluem:
- Experiência e remuneração
- Idade e experiência
- Gênero
- Mobilidade interna e desligamento
- Distribuição geográfica e remuneração
- Variação salarial
- Educação e progressão salarial

## 🎯 Objetivos
- Compreender padrões de remuneração e retenção.
- Identificar desigualdades relacionadas a gênero, idade e escolaridade.
- Gerar insights estratégicos para políticas de gestão de pessoas.

## 🛠️ Tecnologias Utilizadas
- **Databricks** para ETL e modelagem de dados.
- **PySpark** para tratamento e padronização.
- **Delta Tables** para armazenamento confiável.
- **GitHub** para versionamento e documentação.

## 📂 Estrutura do Projeto
- `bronze/` → dados brutos importados dos CSVs.
- `silver/` → dados tratados e padronizados.
- `gold/` → tabelas analíticas e gráficos prontos para responder às perguntas de negócio.
- `notebooks/` → scripts em PySpark utilizados no pipeline.
- `docs/` → relatórios e análises finais.

## 📊 Principais Resultados
- Funcionários mais experientes tendem a estar nas faixas salariais mais altas em ambos os países.
- A relação entre idade e experiência é linear nos EUA e estabiliza cedo na Índia.
- Diferença de retenção entre gêneros é evidente na Índia, mas inconclusiva nos EUA.
- Bangalore concentra as maiores faixas salariais na Índia.
- Educação tem maior impacto na Índia, enquanto nos EUA experiência e desempenho são mais relevantes.
